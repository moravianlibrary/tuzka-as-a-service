# Test images

`map-sample.jpg` is a 2000 × 1623 pixel copy of the historical Jagielnica map sheet
from [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:10_XXXIII_(alt._4475)_Jagielnica_(1-75_000_Spezialkarte_der_%C3%B6sterreichisch-ungarischen_Monarchie).jpg).
The original map is marked **public domain** on its Commons file page. The image was
requested through the Commons API with `iiurlwidth=2000`, then resized to that width
because the API returned a 3840 pixel thumbnail URL.
